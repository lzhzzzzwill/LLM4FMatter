## Introduction

This register is a companion resource for the Review. It maps the public code, datasets, models, prompts, online applications, knowledge bases, and experimental-control software mentioned by the reviewed studies. These resources represent the accumulated knowledge and practical contributions of previous researchers.

The register is organized by the workflow chapters of the Review rather than by repository type. A resource may therefore appear in more than one chapter when it supports multiple stages. A repeated entry is intentional and does not imply a second repository.

Entries are included when the source paper or its associated material explicitly mentions a repository, dataset, model hub, online application, web interface, public portal, or instrument-control project. A link is not inferred from a project name. When a paper mentions an application but does not provide a stable public URL, that limitation is recorded explicitly.

## Access-route key

| Code | Access route                | Meaning                                                      |
| ---- | --------------------------- | ------------------------------------------------------------ |
| A    | Public repository           | Public GitHub repository or equivalent source-code record    |
| B    | Public application          | Public web application, demo, Hugging Face Space, or model portal |
| C    | Reused public source        | External database, model, or software used by the study      |
| D    | Mentioned, link unavailable | The paper describes a resource but does not provide a stable public location |
| V    | Verification required       | A candidate link was recovered from extracted text or a secondary project list and should be opened before citation |

The access route describes the location reported by the source, not a guarantee that the service remains online. GitHub and web URLs should be checked again before submission. No DOI, accession number, licence, embargo, or access condition is invented here.
